## Roles
Como el trabajo fue individual, asumí los roles de todos los integrantes descritos en la guía para generar y resolver el conflicto.

## Explicación del Trabajo
El conflicto se generó modificando la misma línea del archivo `README.md` simultáneamente en el repositorio remoto (GitHub) y en el repositorio local. Al intentar hacer un `git push`, Git rechazó el envío. Se ejecutó `git pull` para traer los cambios, lo que generó el conflicto. El conflicto se resolvió manualmente eliminando los marcadores insertados por Git y conservando la versión final del texto, para luego hacer un nuevo commit y push.
